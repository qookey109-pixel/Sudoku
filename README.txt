Sudoku District V8 — ZH / EN Package
========================================

Base
----
Latest complete V8 Hybrid Generator artifact available in the ChatGPT Project.

Files
-----
index.html      Traditional Chinese version (default)
index-en.html   English version
SHA256SUMS.txt  File checksums

Changes in this package
-----------------------
1. Notes mode toggle:
   - Tap Notes once: enter Notes mode.
   - Tap Notes again: return to Number mode.
2. Auto Candidates toggle:
   - Tap Auto Candidates again: return to Number mode.
3. Existing notes are preserved when switching modes.
4. English version keeps the same puzzles, generator, storage keys, rules,
   and core game logic; only user-facing language is translated.

Usage
-----
Open index.html for Traditional Chinese.
Open index-en.html for English.

GitHub note
-----------
This package is a downloadable build. It does not mean GitHub has been updated
or deployed automatically.
